# 엔진 설계 (채점 · 적응형 · 타당도)

`src/engine/`은 React 없이 동작하는 순수 TS 모듈이다. 모든 상수는 `src/engine/config.ts`에 있다.

## 1. 세션 상태

```ts
interface Session {
  version: string;          // 문항 은행 버전. 다르면 폐기
  seed: number;             // 문항 순서 재현용
  phase: 1 | 2 | 3 | 'done';
  queue: string[];          // 현재까지 확정된 출제 순서 (문항 id)
  index: number;            // 현재 위치
  answers: Record<string, number>;   // 리커트 1–5, 강제선택 1–4
  times: Record<string, number>;     // 응답 소요 ms
}
```

단계가 끝날 때 다음 단계 문항을 `queue` 뒤에 붙인다. 이전 문항으로 돌아가 답을 바꿀 수 있지만, 이미 정해진 다음 단계 구성은 다시 계산하지 않는다.

## 2. 적응형 흐름 (베이즈 순차 + 조기 종료)

| 단계 | 문항 | 수 |
|---|---|---|
| 1 선별 (고정) | 유형마다 측면별 2문항(정문항 1 + 역문항 1) = 108. 일관성 쌍 원문항 8개는 강제 포함. 본능 측면별 2문항 = 24. 타당도 14 | 약 150 |
| 2 적응형 | 남은 유형 핵심·유형 강제선택 문항 중 **기대 정보 이득(EIG)이 가장 큰 문항**을 하나씩 출제. 종료 조건을 만족하면 멈춤 | 가변 (최소 20) |
| 3 마무리 | 본능 강제선택 6(쌍마다 2) + 1·2위 유형 수준 문항 12 | 18 |

**사후확률 모형** (`src/engine/bayes.ts`):
- 가설은 "주유형 = t" 9개이고, 사전확률은 균등이다.
- 리커트 응답은 먼저 역채점한다. 그다음 묵종 경향(지금까지 리커트 원응답 평균 − 3)을 빼서 보정한다.
- 보정한 값 x의 우도는 정규분포 N(μ, σ = 2.2)이다. σ는 실제 응답 분산보다 크게 잡았다. 문항 간 상관을 무시하는 단순 모형이라 σ를 작게 두면 확신이 과해지기 때문이다(시뮬레이션으로 1.0/1.6/2.2/3.0 비교 후 결정).
  - μ = 4.0: 문항 유형 = t
  - μ = 3.3: 문항 유형이 t의 날개
  - μ = 2.6: 그 외
- 강제선택 응답(1–4)의 우도:
  - t = A이면 [0.45, 0.30, 0.15, 0.10]
  - t = B이면 그 역순
  - t가 둘 다 아니면 [0.2, 0.3, 0.3, 0.2]
- 사후확률은 로그 공간에서 누적한다.

**문항 선택:** EIG = H(사후) − E_x[H(사후 | x)]. 응답 x의 예측 분포는 현재 사후확률로 가중한 우도다. 동점이면 아직 덜 출제된 측면을 우선한다.

**종료 조건 (하나라도 만족하면 종료):**
- 2단계 문항이 20개 이상이고 최대 사후확률 ≥ 0.98
- 2단계 문항이 60개 이상이고 최근 10문항 동안 최대 사후확률 변화 < 0.01 (더 물어도 나아지지 않음)
- 출제할 문항이 남지 않음

**확신도**는 이 사후확률의 최댓값을 쓴다. 기존 softmax는 폐기한다.

**1단계 순서 (시드 고정 셔플):**
- 같은 유형 문항은 연속 2개를 넘지 않는다.
- 같은 유형·측면 문항은 붙지 않는다.
- 일관성 쌍 문항은 원문항과 최소 40문항 떨어뜨린다.
- 주의 문항은 각각 30–40%, 65–75% 구간에 넣는다.

방식: 그리디로 배치하고, 제약 위반 시 재시도한다(최대 50회, 실패하면 제약을 완화).

## 3. 채점

| 단계 | 식 |
|---|---|
| 역문항 | `x' = 6 − x` |
| 유형 원점수 | 측면 평균의 평균 (1–5) |
| 묵종 보정 | `z_t = (raw_t − μ) / σ`, μ·σ는 응답자의 유형 원점수 9개의 평균·표준편차 (σ 하한 0.25) |
| 리커트 점수 | `L_t = clamp(50 + 20·z_t, 0, 100)` |
| 강제선택 점수 | 응답 1/2/3/4 → A에 +2/+1/−1/−2, B는 부호 반대. `F_t = 50 + 50·(합 / (2·노출수))` |
| 최종 | 강제선택 노출이 있으면 `0.7·L_t + 0.3·F_t`, 없으면 `L_t` |

**파생 지표:**
- 날개: 주유형 양옆 중 높은 쪽. 차 < 5이면 균형 날개.
- 트라이타입: 각 센터의 최고 유형 3개. 주유형을 맨 앞에 두고, 나머지 둘은 점수 순으로 놓는다.
- 센터: 센터별 3유형 원점수 평균을 0–100으로 환산.
- 본능: 측면 평균 → 원점수. 강제선택은 같은 방식 0.3 가중. 정렬 결과가 스택이다.
- 하위유형: 1순위 본능 × 주유형.
- 통합 수준: `d = mean(healthy) − mean(stress)` (−4…4) → `level = round(5 − d)`를 1–9로 자른다. 1–3 건강, 4–6 평균, 7–9 스트레스.

## 4. 응답 타당도

| 지표 | 계산 | 경고 |
|---|---|---|
| 일관성 | 8쌍 절대차 평균 | > 1.5 |
| 주의 | 지시 문항 오답 수 | ≥ 1 |
| 바람직성 | 4문항 평균 | ≥ 4.25 |
| 직선응답 | 리커트 연속 동일 응답 최대 길이 | ≥ 15 |
| 분산 | 리커트 응답 표준편차 | < 0.6 |
| 속도 | 응답시간 중앙값 | < 1200 ms |

경고가 2개 이상이면 `interpretCaution = true`.

## 5. 시뮬레이션 (`npm run simulate`)

가상 응답자 모형:
- 잠재 성향: 실제 유형 4.3, 날개 3.4, 나머지 2.0–3.2 무작위.
- 응답: `round(성향 + 묵종 편향(±0.5) + N(0, 0.8))`, 역문항은 `6 − 성향`을 기준으로 한다.
- 강제선택: 두 유형 성향 차를 로지스틱으로 변환해 선택한다.

판정 기준:
- 표준 조건 정확도 ≥ 90%, 어려운 조건(주유형 3.9 / 날개 3.6 / 노이즈 1.0) ≥ 75%.
- 확신도 보정표: 표시 확신도 구간별 실제 적중률을 출력해 과신 여부를 확인한다.
- 무작위 응답자 200명 → 80% 이상이 해석 주의 판정을 받아야 한다.
