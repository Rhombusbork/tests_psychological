# UI · 보고서 설계

## 화면 흐름
`#/` 소개 → `#/test` 검사 → `#/result` 결과. 진행 상태는 `localStorage`에 자동 저장하며, 다시 열면 이어하기를 제안한다.

## 검사 화면
- 한 화면에 한 문항. 선택하면 0.15초 뒤 자동으로 다음 문항으로 넘어간다.
- 리커트: 5개 버튼 (키보드 1–5). 강제선택: A/B 카드와 4단계 버튼 (키보드 1–4).
- "이전" 버튼 (키보드 Backspace). 이전 응답이 선택 상태로 표시된다.
- 상단: 단계 이름(1 선별 / 2 변별 / 3 마무리)과 전체 진행률.
- 응답시간은 문항이 표시된 시점부터 측정한다(타당도용).
- 10분 이상 걸린 문항은 시간을 기록하지 않는다(자리 비움).

## 문항 피드백
- 검사 화면 하단 "⚑ 이 문항 이상해요" → 이유 칩(복수 선택)을 고른다. 표시는 세션에 저장된다(`flags`).
- 결과 화면 "표시한 문항" 섹션에서 문항 id·문장·이유·내 응답을 텍스트로 모아 복사한다. 서버 전송은 없다.

## 결과 보고서 섹션
1. 요약: 주유형+날개(예: 4w5), 하위유형(예: SO4), 트라이타입, 확신도
2. 해석 주의 배너 (타당도 경고 ≥ 2)
3. 9유형 점수: 레이더(원 순서) + 막대
4. 후보 유형 비교 (확신도 < 40%이거나 1·2위 차 < 8점일 때): 상위 3유형의 두려움·욕구 비교
5. 주유형 상세: 요약, 두려움·욕구·정서·사고 습관, 강점, 맹점, 성장 방향, 성장·스트레스 방향
6. 주유형 6측면 프로파일
7. 날개
8. 본능 스택과 하위유형
9. 센터 프로파일
10. 통합 수준
11. 응답 타당도 상세
12. 고지, 인쇄, 다시 하기

## 인쇄
`@media print`에서 버튼을 숨기고 섹션 단위로 페이지를 나눈다. 색상은 그대로 출력한다.
