# 문항 설계 명세 (Item Design Specification)

iEQ9 수준의 에니어그램 검사를 목표로 한 문항 은행 설계 문서.
측정 구조는 iEQ9(9유형 · 날개 · 본능 하위유형 · 트라이타입 · 통합 수준 · 센터)를 따르되,
문항은 전부 독자적으로 작성한다.

---

## 1. 측정 구조 (무엇을 측정하는가)

| 측정 영역 | 산출물 | 측정 수단 |
|---|---|---|
| 9유형 | 유형별 0–100 점수, 주유형, 확신도 | 리커트 핵심 문항 + 강제선택 변별 쌍 |
| 날개 | 주유형 양옆 유형의 상대 강도 | 유형 점수에서 파생 |
| 트라이타입 | 센터(장·가슴·머리)별 최고 유형 3개 | 유형 점수에서 파생 |
| 센터 | 장/가슴/머리 활용 프로파일 | 유형 점수 묶음 평균 |
| 본능 | SP/SO/SX 점수 및 스택 순서 → 27 하위유형 | 본능 리커트 + 본능 강제선택 |
| 통합 수준 | 건강/평균/스트레스 수준 (주유형 기준) | 수준 문항 (주유형 것만 채점) |
| 응답 타당도 | 일관성 · 주의 · 바람직성 · 직선응답 지표 | 타당도 문항 + 응답 패턴 분석 |

## 2. 문항 구성 (총 약 400문항, 적응형 노출은 약 300–330)

| 블록 | 구성 | 문항 수 | 형식 |
|---|---|---|---|
| A. 유형 핵심 | 9유형 × 6측면 × 4문항 | 216 | 리커트 5점 |
| B. 통합 수준 | 9유형 × (건강 3 + 스트레스 3) | 54 | 리커트 5점 |
| C. 본능 | 3본능 × 4측면 × 4문항 | 48 | 리커트 5점 |
| D. 타당도 | 일관성 쌍 8 + 주의 2 + 바람직성 4 | 14 | 리커트 5점 |
| E. 유형 변별 | 36개 유형 쌍 × 2 | 72 | 강제선택 (A/B, 4단계) |
| F. 본능 변별 | 3개 본능 쌍 × 4 | 12 | 강제선택 (A/B, 4단계) |

### 2.1 유형별 6측면 (Facet)
문항이 행동 묘사에 치우치면 유형이 오판된다(예: 정리정돈 → 1번? 6번? 5번?).
그래서 각 측면은 **"왜 그렇게 하는가"**, 즉 동기 층위를 겨냥한다.

| 측면 | 정의 | 예 (1번) |
|---|---|---|
| `fear` 핵심 두려움 | 가장 피하고 싶은 상태 | 내가 잘못되었거나 결함이 있는 사람일까 봐 |
| `desire` 핵심 욕구 | 궁극적으로 얻고 싶은 상태 | 옳고 선한 사람이 되는 것 |
| `passion` 격정 | 가슴 센터의 습관적 정서 (분노·자만·허영…) | 겉으로 내지 않는 짜증과 분노 |
| `fixation` 고착 | 머리 센터의 습관적 사고 (원망·아첨·허영…) | "이건 이래야 하는데"라는 반복 사고 |
| `attention` 주의 초점 | 자동으로 주의가 가는 곳 | 오류·불완전함이 먼저 눈에 띔 |
| `defense` 방어기제 | 위협을 처리하는 무의식적 방식 | 반동형성: 불쾌한 감정을 반대 행동으로 덮음 |

## 3. 문항 작성 규칙 (Item Writing Guidelines)

1. **동기 중심.** "나는 ~한다"보다 "나는 ~하지 않으면 불안하다", "~하는 것이 나에게 중요하다"처럼 동기를 드러낸다.
2. **단일 개념.** 한 문항에 하나의 생각만 담는다. "그리고/또는"으로 두 개념을 묶지 않는다(이중 질문 금지).
3. **일상 언어.** 에니어그램 전문 용어(격정, 고착, 날개 등)를 쓰지 않는다.
4. **습관적 경향.** "대체로", "자주", "나도 모르게" 같은 표현으로 특정 순간이 아닌 평소 패턴을 묻는다.
5. **바람직성 중립.** 모든 유형의 문항이 비슷하게 매력적이거나 비슷하게 불편하도록 쓴다. 칭찬처럼 들리는 문항(정의로움, 따뜻함)과 비난처럼 들리는 문항(이기적, 게으름)의 쏠림을 피한다.
6. **역문항은 반대 극으로.** 역문항은 "~하지 않는다" 같은 부정형 대신 반대 성향을 긍정형으로 진술한다.
   - 나쁜 예: "나는 실수를 신경 쓰지 않는 편이 아니다."
   - 좋은 예: "일이 대충 끝나도 크게 신경 쓰이지 않는다." (1번 역문항)
   - 역문항은 유형당 6개(측면당 1개), 약 25%를 차지한다. 묵종 편향(무조건 동의) 보정에 쓴다.
7. **타 유형과의 변별.** 문항이 다른 유형의 핵심 동기에도 해당되면 다시 쓴다. 혼동이 잦은 쌍(1-6, 2-9, 3-8, 4-5, 5-9, 6-9, 7-3 등)은 특히 주의한다.
8. **1인칭 · 현재형 · 40자 내외.**

## 4. 응답 형식

### 4.1 리커트 5점
| 값 | 라벨 |
|---|---|
| 1 | 전혀 그렇지 않다 |
| 2 | 그렇지 않은 편이다 |
| 3 | 보통이다 |
| 4 | 그런 편이다 |
| 5 | 매우 그렇다 |

### 4.2 강제선택 4단계 (양극 척도)
"A가 훨씬 더 나와 같다 / A가 약간 더 / B가 약간 더 / B가 훨씬 더"
중립 선택지를 없애 반드시 한쪽을 고르게 한다. 두 선택지는 같은 측면(예: 둘 다 두려움)을 비슷한 바람직성으로 진술해서, 매력도가 아니라 동기 차이로 고르게 만든다.

## 5. 제시 순서와 적응형 흐름

```
1단계  선별 (A 216 + C 48 + D 14, 무작위 섞음, 같은 유형 연속 2문항 이내)
        ↓  잠정 유형 점수 계산
2단계  변별 (E: 상위 4개 유형 간 6쌍 × 2 = 12문항 + 1·2위 차이가 작으면 추가)
        (F: 본능 6–12문항)
        ↓  주유형 확정
3단계  수준 (B: 주유형 6문항 + 2위 유형 6문항)
```

- 섞기 규칙: 같은 유형이나 같은 측면 문항이 연달아 나오지 않게 한다. 역문항은 고르게 퍼뜨린다.
- 2단계 추가 규칙: 1·2위 정규화 점수 차가 8점 미만이면 해당 쌍의 남은 변별 문항과 3위 쌍까지 추가한다.
- 진행률은 단계별로 표시한다.

## 6. 채점

### 6.1 유형 점수
1. 역문항 변환: `x' = 6 − x`
2. 측면 점수 = 측면 4문항 평균, 유형 원점수 = 6측면 평균 (1–5)
3. **개인 내 표준화(ipsatization) 보정:** 응답자의 전체 리커트 평균(묵종 경향)을 빼서 "모든 문항에 높게 답하는 사람"의 편향을 제거한다.
   `z_t = (raw_t − mean_all) / sd_all`
4. 강제선택 반영: 각 변별 문항은 선택한 유형에 +2/+1, 상대 유형에 −2/−1을 준다. 유형별 합산을 노출 횟수로 나눠 `fc_t`를 구한다.
5. 최종: `score_t = 0.7·norm(z_t) + 0.3·norm(fc_t)` → 0–100. 변별 문항을 받지 않은 유형은 리커트 점수만 쓴다.

### 6.2 확신도
`p_t = softmax(score_t / τ)` (τ = 8). 주유형 확신도는 `p_1`.
`p_1 < 0.4`이면 "후보 유형 비교" 섹션을 보고서에 노출한다.

### 6.3 날개 · 트라이타입 · 센터
- 날개: 주유형 양옆 두 유형 중 점수가 높은 쪽. 두 날개 차이가 5점 미만이면 "균형 날개"로 본다.
- 트라이타입: 장(8·9·1), 가슴(2·3·4), 머리(5·6·7) 각 센터 최고 유형을 주유형 센터부터 순서대로 나열한다.
- 센터: 각 센터 소속 3유형 점수의 평균.

### 6.4 본능
측면 평균 → 본능 원점수, 강제선택 0.3 가중 → 순위 = 스택(예: SO/SP/SX). 1순위 본능 × 주유형 = 27 하위유형.

### 6.5 통합 수준
`level = mean(healthy) − mean(stress)` (−4 … +4) → 9단계 수준 척도로 대응:
`+2.0 이상` 건강(1–3), `−1.0 ~ +2.0` 평균(4–6), `−1.0 미만` 스트레스(7–9).

### 6.6 응답 타당도
| 지표 | 계산 | 경고 기준 |
|---|---|---|
| 일관성 | 8개 쌍(같은 의미, 다른 표현)의 절대차 평균 | > 1.5 |
| 주의 | 지시 문항 정답 여부 | 1개 이상 오답 |
| 바람직성 | "한 번도 ~한 적 없다" 4문항 평균 | ≥ 4.25 |
| 직선응답 | 연속 같은 응답 최대 길이 | ≥ 15 |
| 응답 분산 | 리커트 응답 표준편차 | < 0.6 |
| 속도 | 문항당 중앙 응답시간 | < 1.2초 |

경고가 2개 이상이면 결과 상단에 "해석 주의"를 표시한다.

## 7. 문항 품질 자동 검증 (`npm run validate`)
- 유형마다 측면별 4문항, 측면별 역문항 정확히 1개
- ID 중복 없음, 문장 중복 없음
- 문항 길이 10–60자
- 금지어(전문 용어) 미포함: 에니어그램, 날개, 격정, 고착, 본능, 유형
- 이중 질문 의심 패턴("그리고", "또는", "~고 ~며") 경고
- 강제선택: 36개 유형 쌍 모두 2문항씩, 선택지 길이 차이 경고(바람직성·길이 균형)
