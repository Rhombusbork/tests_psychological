**그 밖의 변경:**
- 본능 강제선택 12문항: 같은 문장이 두 쌍에서 반복되던 구조를 버리고, 쌍마다 4개 상황(돈, 안정감, 모임, 걱정 등)을 새로 썼다.
- 과장 응답 탐지 문항: 4개에서 8개로 늘렸다 (V-D5–8, "언제나 / 완벽하게" 유형의 은근한 자기과장).
- 응답 기준 안내: 시작 화면에 "직장과 사생활을 아우른 평소 모습", 수준 문항 화면에 "최근 한 달 기준"을 표시한다.
- 검증 스크립트: 규칙 9–14 위반 패턴, 문장 유사도, 강제선택 문장 재사용을 오류로 처리한다.
